# Privacy

Orbitkeep may record how each Play session went so we can balance the game.

## What we collect when you opt in

- An anonymous install id created on your device
- Run outcome: planet, win or defeat, wave, duration, score, build version
- Fleet and combat choices: loadout, satellite purchases by type and orbit ring, specialization branches, sells, satellite losses
- Draft upgrades offered and picked
- Economy signals: extractor dust, peak and ending stardust, crystals
- Station tech owned: HULL, MAGNET, CACHE
- Earth hull remaining, enemy kinds destroyed, and whether a tactical item was used

## What we do not collect

- Your name or email
- Advertising identifiers
- Precise location
- Screen recordings or session replay

## Choice

Telemetry is off until you accept the in-game prompt. You can turn it off later in Options, Privacy. Turning it off stops new run reports.

## Use

We use this data to find overpowered satellites, weak planets, and economy spikes. We do not use it for ads.
